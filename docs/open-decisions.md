# Open Decisions

The following decisions remain open and should be resolved before the project expands beyond the initial architecture scaffold.

## Product decisions

- Launch geography: Nigeria-only or broader international launch
- Payment provider: Paystack, Flutterwave, Stripe, or another provider
- Tutor matching model: managed matching or open marketplace-style discovery
- Lesson delivery approach: integrated video provider or a lightweight link-based model

## Architectural decisions

- Session strategy: cookie-based sessions or short-lived access/refresh tokens
- File storage: object storage provider and signed URL strategy
- Notification provider: internal queue plus email/SMS provider abstraction
